POCT Result File Analysis - How to run
=======================================

REQUIREMENTS
  - Windows PC
  - Python 3.9 or newer (if you don't have it: https://www.python.org/downloads/)
    During Python setup, check "Add Python to PATH".

HOW TO RUN
  1. Unzip this folder anywhere (e.g. Desktop).
  2. Double-click "run.bat".
  3. Your browser will open to the analysis page.
  4. Upload a POCT result file and click "Analyze".
  5. To stop: close the black command window.

FILES IN THIS FOLDER
  - run.bat          Double-click this to start the app.
  - app.py           The web app (do not delete).
  - poct_checks.py, poct_line_checks.py  Required (do not delete).
  - requirements.txt  List of Python packages (used by run.bat).

If run.bat says "Python is not installed", install Python from
https://www.python.org/downloads/ and make sure to check
"Add Python to PATH" during installation.
